# ADR-2026-09-25: Monetization ladder

## Status

Accepted as **product policy**. Billing is **not implemented**. No Snowshoe ARR or user counts exist; unknown stays `unknown`.

## Context

Snowshoe is a personal-first, git-native catch-up map (see CURRENT). The OSS /
local core is free forever. Paid layers and price hypotheses are **not** public
canon: they live in private maintainers docs (sibling `snowshoe-maintainers`,
path `docs/private/notes/monetization-analogs-2026-09-25.md` after
`./scripts/link-private-overlay.sh`).

There is **no proven public price anchor** for a “personal comprehension map
after pull.” Do not invent one on a landing page.

## Decision

1. **Now / v1:** OSS / local-first core **free forever**. Not a core paywall.
   Billing is not implemented.
2. **Later (intent only, not a ship commitment):** optional paid convenience and,
   when shared surfaces exist, team seats — details and WTP hypotheses stay
   private until promoted by a future ADR + CURRENT update.
3. **Do not (public posture):**
   - Enterprise-only or high minimum seats day-1
   - AI-review price or messaging
   - Freemium that is “another chat” or “another wiki” without the git-freshness wedge
   - Promise multiplayer knowledge graph / agent control in v1 packaging
   - Depend on one host/IDE as the only distribution
   - Publish invented ARR, users, or dollar price bands

## Consequences

- CURRENT stays thin: free forever, no billing, no public WTP dollars.
- Positioning matches; no competitor price-shelf copy.
- Private maintainers hold analogs, WTP sketch, and paid-hook candidates.
